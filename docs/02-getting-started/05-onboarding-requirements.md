# Onboarding requirements

Currently, LayerNext requires data to be stored on one or more S3 compatible cloud data storage.

LayerNext is currently deployable on AWS and we are working to provide deployment instructions for Google Cloud and Microsoft Azure.

LayerNext UI applications are accessible on all modern browsers.

To use LayerNext in your training environment, it must be able to install Python CLI tools or Python dependencies.
