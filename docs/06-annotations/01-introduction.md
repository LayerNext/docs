# Introduction

LayerNext Studio can be used to annotate images or video. Studio is designed for collaborations. ML engineering team and annotation team can communicate within the Studio. Annotation projects can be created from image or video collections sitting in the DataLake. Once an annotation project is created, it will automatically generate annotation tasks. Tasks can be signed to annotation team members for annotation. LayerNext Studio supports Bounding Box, Line and Polygon annotation types. Additionally LayerNext Studio supports attribute level annotation. For example, Class is Car and Attribute can be Color. In order to make sure the quality of the annotation, quality control workflow is included in the annotation workflow.

LayerNext Studio supports interpolation based carryforward annotation for video annotations.
